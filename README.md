# 📰 News Recommendation System using NLP

A web-based News Recommendation System that suggests similar news articles based on user input using Natural Language Processing techniques.

---

## 🚀 Features

- 🔍 Search-based news recommendation
- 🧠 TF-IDF vectorization
- 📊 Cosine similarity scoring
- 🌐 Flask-based web application
- 🎨 Clean and responsive UI
- ⚡ Fast and efficient results

---

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- NLTK
- HTML & CSS

---

## ⚙️ How It Works

1. User enters a news topic (e.g., "cricket match")
2. Input is cleaned using NLP techniques
3. TF-IDF converts text into numerical vectors
4. Cosine similarity calculates similarity between articles
5. Top 5 most relevant news articles are displayed
